## 2. ⭐ The AOPO board has been under-recorded for months — 81 listings were never in `seen.csv`

`vendors.txt` says AOPO is **browser-tier only**: *"curl and WebFetch both return zero listings
(client-side rendered)... navigate, wait ~14s, then click 'Load more listings' up to 5x."* Chrome MCP
was unavailable this run (another session holds the profile), so I went looking for an alternative.

**AOPO is WordPress. The job board is a `job_listing` custom post type with a public REST route:**

```
https://aopo.org/wp-json/wp/v2/job-listings?per_page=100&page=1&orderby=date&order=desc
```

Plain `curl`, no browser, full JSON with titles, links, and post dates. **98 listings returned.**

**Of those 98, only 17 were in `seen.csv`.** The browser tier was rendering ~100 listings per run and
the vast majority were never being written down — which means every "AOPO scanned, nothing new" line
in the last several reports was covering a fraction of the board. All 81 are now recorded.

**What the backlog actually contained, after triage: no new 4-5.** But it contained something more
useful — a clean confirmation of the near-miss pattern from 08-02. Four roles carry the exact
paramedic-accepted gate language he needs, and all four die on geography or money, not on
qualifications:

| Role | The gate language, verbatim | What kills it |
|---|---|---|
| **LifeLink — Transplant Coordinator 1** (Tampa FL) | *"Licensed healthcare professional with critical care experience, such as a Registered Nurse (RN), **Paramedic**, Respiratory Therapist (RT)... with 1-2 years of ICU, OR, ED, or **pre-hospital** critical care"* | `geo:hard-skip` (FL). Nothing else. This is the single best OPO gate language in the file — it counts pre-hospital time explicitly. |
| **Life Alliance — Procurement Transplant Coordinator I** (Miami Lakes FL) | *"Associate's or Bachelor's degree or higher in nursing, respiratory therapy, **paramedic medicine**"* + *"CPTC required within 18 months of employment"* | `geo:hard-skip` (FL) |
| **Clinical Referral Specialist** (Richmond VA) | *"Associate Degree"* + *"Respiratory Therapist (RT), Advanced EMT, EMT-I, or **EMT-P**, LPN or RN"* + 2 yrs clinical | `comp:below-floor` — $24.64–32.85/hr = $51.3–68.3K |
| **TDS — Referral Screening Specialist** (Knoxville TN) | *"A minimum of a two-year degree in a health-related field, nursing or **paramedic/EMT certification** or combination of equivalent experience"* | Comp not posted + HB-4 + screening/intake function |

**`CPTC` recurs again.** Per the 08-02 note, it is the one credential that keeps appearing between
him and the OPO board. It shows up here as *"required within 18 months of employment"* — i.e. a
post-hire pathway, not a hiring wall. That is worth knowing: the OPO lane's recurring credential is
frequently obtainable *after* hire.

**`vendors.txt` edit warranted:** replace the AOPO browser-tier block with the REST endpoint above.
