### Spatial Computing / 3D

- **Meta XR Simulator with VR Glasses profile (v207)** — [VR.org](https://vr.org/articles/meta-vr-glasses-store-hand-tracked-apps-first-v207-sdk-2026) · [Meta developer recap](https://developers.meta.com/blog/meta-connect-recap-start-building-the-future-of-vr/) — Runs Meta VR Glasses target on a desktop with no headset; tracks hands via the laptop's webcam. **Why it matters:** eliminates the "no hardware = no dev" gate. - **World Labs Atlas — omni world model** — [World Labs blog](https://www.worldlabs.ai/blog/atlas) · [The Decoder coverage](https://the-decoder.com/world-labs-unveils-atlas-a-single-ai-model-that-generates-reconstructs-and-simulates-3d-worlds-from-just-a-few-photos/) · [How AI Works overview](https://howaiworks.ai/blog/world-labs-atlas-world-model-2026) — Announced Sep 1, 2026 (outside window, but flagging because it wasn't fully caught prior). Multimodal autoregressive diffusion transformer on text/images/video/3D. Camera-controlled video generation up to 1min at 1440p from one or more reference images with the camera path supplied as geometric input. **Currently early-access with select partners behind a request form — no public API, no pricing.** **Why it matters:** this is the direct competitor to Genie 3 for the ai-multiview-video-generator blocker, and unlike Genie 3 it accepts an explicit camera-path input — which is *exactly* the multi-view export capability the parked idea was waiting for. But same problem: no API. Submit to the early-access form now to see if we can get a look; that's the actionable unblock signal.
- **Multi-view 3D hand-pose surgery dataset (IJCARS, June 2026)** — [PubMed 42113334](https://pubmed.ncbi.nlm.nih.gov/42113334/) · [Springer Nature](https://link.springer.com/article/10.1007/s11548-026-03610-6) · [arxiv preprint](https://arxiv.org/abs/2601.15918) — Not new this week (June 2026 publication), but I did not find it in prior scout coverage so I'm flagging it now. 68K frames, 3K manually annotated 2D hand poses with triangulated 3D ground truth, recorded in a **high-fidelity physical operating room replica**. Off-the-shelf pretrained models, no domain-specific fine-tuning, constrained 3D optimization. **Why it matters — MedCapture-critical:** this is peer-reviewed prior art for exactly the MedCapture dataset thesis. Confirms (a) academic reviewers accept OR-replica-derived hand-pose data as publishable, (b) 2D-to-3D triangulation from multi-view is the established methodology (relevant to `medcapture-stereo-second-camera.md`), (c) the dataset scale threshold for a benchmark paper is on the order of tens of thousands of frames. Should be a citation in MedCapture's first paper.
